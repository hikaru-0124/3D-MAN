# ボンバーひろば

一人称視点の3Dボンバーゲーム。CPU戦と2〜4人の通信対戦ができます。PCのキーボード・マウス、スマホのタッチ操作で遊べます。

## 起動

Node.js 20以上で `npm install`、`npm start` を実行し、http://localhost:3000 を開いてください。
Codespacesでは「ポート」タブから3000番の転送URLを開けます。友達に共有する場合は公開設定をPublicにしてください。

## 通信対戦

1. ユーザーネームを入力して「部屋を作る」を押します（12文字まで、未入力時は自動で名前をつけます）。
2. 「招待URLをコピー」で友達にURLを送ります。6桁の部屋コードでも参加できます。
3. 友達がURLを開き「参加する」を押します。
4. 2〜4人そろったらホストが「対戦開始」を押します。
5. 各プレイヤーが「対戦に参加」を押すと操作できます。

名前は参加者一覧と勝敗表示に反映され、同じブラウザーでは次回も入力済みになります。変更するときは部屋を退出し、名前を入力して入り直してください。

最後に生き残った人が勝ちです。同時に全滅すると引き分け。同じ部屋でもう一度対戦できます。対戦中の途中参加はできません。切断したプレイヤーは脱落し、ホスト退出時には次の参加者へホストを引き継ぎます。操作中断時も通信対戦は続きます。切断後は部屋に入り直してください。

Codespacesが起動している間に利用できます。サーバーを再起動すると部屋は消えます。

## 操作

- WASD: 移動（毎秒2.4マス）
- マウス: 上下左右に視点移動 / 左右矢印: 水平の視点回転
- Space: 爆弾設置（2.5秒後に爆発）
- Esc: 操作を中断

爆風は十字方向に伸び、壁で止まります。破壊可能ブロックを壊すと確率で爆風・設置数の強化アイテムが出ます。爆弾は連鎖し、自分にも相手にもダメージがあります。
爆発予定のマスは床とミニマップにオレンジで表示され、残り1秒以内は赤くなります。自分が予告範囲内にいる場合は残り秒数と警告を表示します。壁・ブロック、連鎖爆発による時刻やブロック破壊も予告に反映します。新しい爆弾が置かれると範囲は更新されます。
プレイ画面はブラウザー全体に表示されます。ステータスは上部、拡大マップは右上です。

## CPU戦

CPUは爆風と連鎖爆発を予測し、退路を確認してから爆弾を置きます。危険なマスからの脱出を優先し、ブロックを壊しながらプレイヤーへ近づき、強化アイテムも拾います。CPUの移動速度はプレイヤーと同じです。無敵ではなく、追い込まれた場合は倒せます。

## スマホ操作と軽量化

- 左スティック: 移動
- 画面を上下左右にスワイプ: 視点操作（移動と同時に操作可能）
- 右側の「爆弾」ボタン: 爆弾設置
- 「Ⅱ」ボタン: 操作中断

縦・横画面に対応し、スマホではマウスロックを使いません。タッチの中断やアプリを切り替えたときには移動入力を解除します。
画質はメニューから「自動」「軽量」「高画質」を選べます。自動設定はスマホで描画の長辺を640px以下・30fpsを目標にし、描画に時間がかかる場合は解像度をさらに落とします。PCの自動設定は長辺900px以下です。メニュー表示中は描画頻度を下げます。
ステータスとマップは最大10回/秒で更新し、変化のないステータスを書き直しません。通信ではマップを開始時とブロック破壊時だけ送り、部屋全体で共通の状態JSONを一度だけ生成します。

## 構成と検証

`src/game.js` に共通ゲームルール、`src/rooms.js` に部屋とサーバー上のゲーム進行、`src/main.js` に入力・表示・接続処理、`server.js` にHTTP/WebSocketサーバーがあります。移動・爆弾・アイテム・勝敗はサーバーが判定し、20回/秒で状態を配信します。通信ライブラリは `ws` です。

`npm test` でルールと部屋管理を検証します。
サーバー起動中に `node scripts/check-multiplayer.js` で2接続による通信検証を実行できます。別URLの検証は `GAME_URL=https://… node scripts/check-multiplayer.js` です。

4人接続の検証は `node scripts/check-four-players.js` で実行できます。
